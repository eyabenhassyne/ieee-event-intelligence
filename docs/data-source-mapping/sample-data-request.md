# Sample Data Request

## Purpose

This document defines the sample datasets required to begin the design and
implementation of the IEEE Event Intelligence Platform.

The requested data will be used only for:

- data-source analysis;
- data profiling;
- ETL development;
- dimensional-model design;
- KPI validation;
- Power BI prototype development;
- testing and documentation.

## Requested Data

### 1. IEEE vTools Events Export

Please provide an authorized sample export containing, where available:

- event ID;
- event title;
- start date;
- end date;
- event status;
- event category;
- event subcategory;
- host organizational unit;
- co-host organizational unit;
- location;
- modality;
- publication date;
- report status;
- report submission date.
