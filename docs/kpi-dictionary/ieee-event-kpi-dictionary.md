# IEEE Event KPI Dictionary

## Notes
- Missing attendance is never treated as zero.
- Averages exclude NULL attendance values.
- Supported KPIs are limited to what the current warehouse snapshot can support.
- Unsupported areas: registration conversion, no-show, feedback, satisfaction, promotion effectiveness, reporting compliance, cost per attendee.
